## 先把"IPLC 裸金属服务器"拆开看

很多人把这两个词混在一起叫，但实际是两个独立概念。

IPLC 全称 International Private Leased Circuit，是一种跨国点对点的物理专用链路。它走的是 SDH/MSTP 这类运营商级传输平台，相当于在两个国家的两个机房之间铺一根专属光纤。和走普通公网（互联网）相比，IPLC 的延迟、抖动和丢包率都更稳定，不会在晚高峰出现明显劣化。

裸金属服务器（Bare Metal）则是另一种形态：它不是云服务器那种在虚拟化层之上分配的实例，而是直接把整台物理服务器交给用户使用。CPU、内存、磁盘 I/O 都不和别的用户共享，也没有 Hypervisor 的开销。

这两者叠在一起意思就很清楚：跨境的物理专用链路上，放一台独立物理服务器给你跑业务。它比普通 VPS 更接近"专线 + 真机"的组合，对延迟敏感、对资源隔离有要求的跨境业务很有吸引力。

但成本也是双重的：IPLC 专线本身按运营商报价就比普通国际带宽贵，裸金属再叠一层硬件资源，它的价格自然不便宜。

## 什么人真的会需要 IPLC 裸金属

把需求列清楚再看值不值得上：

- 跨境电商运营（eBay、Amazon、独立站、TikTok Shop 等），需要稳定的中国—海外出口，同时希望入口端识别稳定、不被连坐封禁。
- 出海企业的对外服务节点，例如海外支付、海外客服系统、游戏产品的多区域接入。
- 远程办公 / 跨境团队协作，要求稳定的中港、中日、中美通道。
- 高频数据采集 / 业务回传场景，例如将海外节点的运行数据稳定回传国内。
- 对虚拟化层敏感的业务，比如某些大内存数据库、缓存层，希望直接拿到物理 I/O。

如果你的业务只是临时跑个轻度爬虫、或者每次只有几百兆流量，普通国际带宽 VPS 就够了，"IPLC + 裸金属"不一定划算。

## 选购前必须先搞清的 6 个差异

1. 云服务器 vs 独立物理服务器。同样在一家厂里下单，有时候给的是 KVM 虚拟化后的 VPS，有时候是整台物理机。Mkcloud 在所有常规产品页都标注"可选云服务器或独立物理服务器"，下单时需要按需切换。

2. 共享带宽 vs 独享带宽。共享带宽便宜，但晚高峰会拥堵；独享带宽价格高，但速率是写死的。Mkcloud 把这两套独立成不同下单入口，不要混着看。

3. 流量计费 vs 带宽计费。流量计费按月用量限制，带宽计费按速率上限、不限流量。跨境专线流量包价格不便宜，先估算实际月流量再选。

4. 双向独享 IPv4。Mkcloud 的专线 VPS 标配"入口 + 出口各 1 个独立 IPv4"，这在做正规跨境业务时能避免共用 IP 带来的风控连坐。

5. 入口省份白名单。所有专线产品需要在附加选项里选 1 个允许连入的省份，后续可以更换，但任何时刻只允许设定省份的 IP 连入。这一条和"机场 / 翻墙"用法完全相反，能否接受很关键。

6. 端内延迟。官网直接给出"端内延迟"区间（如广港 1~2ms、沪港 21ms、沪日 25~28ms、沪美 124~134ms），这是从入口到出口 VPS 之间的内部参考延迟，业务侧实际延迟仍受本地接入、运营商和出口路由影响。

## 怎么选线路：按访问目标看

不是越贵越好，关键是看访问目标。

**广港 IEPL**：端内延迟 1~2ms 是几条线里最低的，价格档和沪日 IPLC 几乎对齐。如果你做的是面向香港的合规跨境业务、希望入口体验最稳，这条是首选入口。广东作为入口侧可对接八线动态 BGP / 电信 / 移动 / 联通 / 三线多种接入。

**沪港 IPLC**：延迟 21ms，比广港略高但代价不大。优势在于沪港是大陆企业出海的传统强通道，运营商资源更成熟，适合大量级业务。

**沪日 IPLC**：25~28ms 的端内延迟，做日本市场、做东南亚中转、做日本云对接都比较合适。日本 BGP 出口通常对游戏和视频服务有针对性路由。

**沪美 IPLC**：124~134ms 的端内延迟是最长的，但跨太平洋是物理距离决定，没办法绕开。相对走普通国际带宽的优势是抖动和丢包更稳定。如果你面向北美用户、又不想用普通公网，沪美 IPLC 至少能让出口侧可控。

**上云互联优化（IXP）**：这一类其实是另一种思路：你的入口是国内云厂网络（阿里云、腾讯云、百度云、火山云、华为云华东、UCloud 华东），所以延迟才压到 21ms；适合已经在阿里云、腾讯云等机房里有部署，想把出口"延伸"到香港 / 日本 / 美国的业务方。

**沪港 IXP 独享带宽大套餐：如果你要的就是裸金属**：套餐页写得很直白——1G/2G/5G 独享方案"赠送志强金牌独立服务器"，是真正免虚拟化的物理机。28 核 64GB 512GB NVMe 这套配置，跑数据库、做大数据缓存都没问题。代价很明显：¥19000 起、¥38000、¥95000 三档。

> 选型思路小结：先看你的访问目标在哪个国家/地区，再看入口侧怎么连入，最后看是要物理机还是要云服务器。如果你的业务在云厂内网发布、对延迟不敏感、对预算敏感，IXP 流量计费档更划算；如果业务必须用到独立物理 I/O 性能，再考虑 1G 以上独享档。

在跨境专线商家之间选择时，合规和售后规则比单纯比价格更影响最终使用体验，下面这些条款要在开通前确认清楚：

- **省级白名单**：每个产品下单时必须绑定 1 个允许连入的省份，业务只能从该省所属 IP 连入。后续可以改，不收费，但用前要清楚自己客户的网络出口偏向哪个省。

- **支付方式**：官网目前仅支持支付宝。如果有发票对公付款需求，需要先和官方沟通。
- **用途合规**：明确禁止机场 / 翻墙等违法违规用途，一经发现会直接清退不退款。

## 常见问题

**IPLC 裸金属服务器和普通跨境 VPS 最大的差别是什么？**

IPLC 让跨境网络抖动可控，裸金属则让 CPU、内存、I/O 资源独享。两者叠加之后，业务可以同时在网络性能和计算性能两个维度上避免被邻居影响。代价是价格高，开销基本是普通 VPS 的几倍到几十倍。

**Mkcloud 所有套餐都能选独立物理机吗？**

在常规线路（广港 IEPL、沪日 IPLC、沪港 IPLC、沪港 IXP 流量计费档）的套餐页，"可选云服务器或独立物理服务器"是明确标注的选项。沪港 IXP 1G/2G/5G 独享套餐则直接在套餐名下方写明"赠志强金牌独立服务器"，是裸金属方案。其他独享带宽档位（如 100M/200M/500M）是默认云服务器形态，确认下单前可以再校验一次。

**哪个线路最适合跨境电商？**

跨境电商要看具体平台节点。如果面向香港买家或用香港仓储发货，广港 IEPL 端内延迟 1~2ms，几乎是最优解；面向日本市场（部分品牌站、独立站）用沪日 IPLC；面向北美买家用沪美 IPLC；如果你的内部运营系统已经在阿里云、腾讯云里，那么沪港 IXP 上云互联优化最贴合。

**优惠码怎么用？**

Mkcloud 的官方购物车页有"优惠劵码"输入框（需登录后显示具体可用码）。第三方测评站常驻的几个循环折扣码（如 IPLC / IEPL / IXP 各自不同形式）来源各异，使用前可以在结算页直接输入看是否生效，避免错过也没必要轻信高价码。
